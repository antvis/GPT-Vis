Thresholds & targets / ANNOTATION GUIDE

target

Draw a fixed target or an ordered path of complete baseline coordinates.

Live examples2ConfigurationChart support5Configuration & support matrix

When to use it

  • Compare measurements with a fixed target.
  • Draw a baseline that changes over the input sequence.

See it in action.

Compare parameter variations. Switch to Code to copy an example with the active theme.

02 / CONFIGURE

Make it yours.

Add this configuration to the annotations array in your chart JSON.

Configuration

PropertyTypeRequiredDefaultDescription
type'target'required—Exact annotation type; keep the spelling and capitalization shown here.
targetnumberoptional—Fixed finite target; required unless data supplies a baseline path.
axis'x' | 'y'optional'y'Logical data axis, independent of chart transposition.
dataAnnotationData<T>[]optional—Ordered baseline coordinates; required when target is omitted.
labelstringoptional—Override the computed label; use an empty string to hide it.
styleAnnotationStyle<'target'>optional—Reuse the shared style definition with the fields supported by this annotation type.

Calculation rules & limits

  • Use either target or data, never both. A path needs at least two complete axis coordinates in input order.
