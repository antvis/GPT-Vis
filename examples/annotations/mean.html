Statistical references / ANNOTATION GUIDE

mean

Compute an arithmetic mean and draw a dashed axis reference.

Live examples2ConfigurationChart support5Configuration & support matrix

When to use it

  • Put individual measurements in statistical context.
  • Compare observations with a central reference.

01 / EXPLORE

See it in action.

Compare parameter variations. Switch to Code to copy an example with the active theme.

Default configuration · Line Chart

Reference on the numeric X axis · Scatter Chart

02 / CONFIGURE

Make it yours.

Add this configuration to the annotations array in your chart JSON.

Configuration

PropertyTypeRequiredDefaultDescription
type'mean'required—Exact annotation type; keep the spelling and capitalization shown here.
axis'x' | 'y'optional'y'Logical data axis, independent of chart transposition.
dataSelectionoptional—Limit calculations to matching original observations; omit to use all input data.
labelstringoptional—Override the computed label; use an empty string to hide it.
styleAnnotationStyle<'mean'>optional—Reuse the shared style definition with the fields supported by this annotation type.
