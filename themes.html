A theme you can take anywhere

Use a built-in preset by name. After customization, export the JSON and pass the complete object.

import { GPTVis } from '@antv/gpt-vis';

const chart = new GPTVis({
  container: '#chart',
  theme: 'gpt-vis',
});

chart.render({
  type: 'line',
  data: [
    { time: 'Q1', value: 32 },
    { time: 'Q2', value: 48 },
    { time: 'Q3', value: 61 },
  ],
});
