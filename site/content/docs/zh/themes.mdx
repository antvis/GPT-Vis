<h2 id="built-in-theme-names">内置主题名称</h2>

`BuiltinThemeName` 支持下表中的名称，可传给构造函数、图表 JSON 或 Syntax。自定义 JSON 对象的结构请参考 [ThemeSpec](/zh/docs/reference/theme-spec)。

```typescript
const chart = new GPTVis({ container: '#chart', theme: 'pop' });
```

<h2 id="customize-a-gallery-theme">调整预设主题</h2>

1. 打开[主题工作台](/zh/themes)，选择一种预设风格。
2. 调整主题 JSON 或导入自己的配置，检查不同图表的效果。
3. 下载 JSON，传给 `new GPTVis()`。

编辑预设后，需要传入完整的 JSON 对象才能保留修改。自定义对象的 `id` 只是元信息，不会注册新的主题名称。

```typescript
import { GPTVis, type ThemeSpec } from '@antv/gpt-vis';
import theme from './my-theme.json';

const chart = new GPTVis({
  container: '#chart',
  theme: theme as ThemeSpec,
});

chart.render({
  type: 'line',
  data: [
    { time: 'Jan', value: 120 },
    { time: 'Feb', value: 180 },
  ],
});

// Subsequent renders in this container keep the theme.
chart.render({
  type: 'table',
  data: [
    { Month: 'Jan', Revenue: 120 },
    { Month: 'Feb', Revenue: 180 },
  ],
});
```

每个实例向一个容器渲染。需要同时显示多张图表时，为每个容器创建实例，并复用同一份主题对象。

<h2 id="create-your-own-theme">创建自己的主题</h2>

先用 tokens 定义各图表共用的样式，再通过 `style` 调整公共细节，通过 `charts` 覆盖某一种图表的样式。

```typescript
import type { ThemeSpec } from '@antv/gpt-vis';

const theme: ThemeSpec = {
  id: 'annual-report',
  label: 'Annual report',
  baseTheme: 'default',
  tokens: {
    colorDefault: '#176b68',
    colorBackground: '#faf8f2',
    colorText: '#233c3b',
    colorTextSecondary: '#637672',
    category10: ['#176b68', '#d38452', '#739ab0', '#a18c67'],
    fontFamily: 'Arial, sans-serif',
    fontSize: 12,
    radius: 4,
  },
  style: {
    title: { titleFontWeight: 700 },
  },
  charts: {
    line: { style: { mark: { line: { lineWidth: 3 } } } },
  },
};
```

如果有品牌参考，可以让 Agent 按照 Skill 中的[主题创建指南](https://github.com/antvis/GPT-Vis/blob/ai/skills/chart-visualization/references/theme-creator.md)生成配置。从主题工作台复制提示词，补充网站或幻灯片参考，再将生成的 JSON 粘贴回来预览。

<h2 id="how-overrides-work">覆盖规则</h2>

外观按以下顺序解析，后面的值优先：

**内置默认值 → tokens → 公共 style → 图表专属 style → 单次渲染 style**。

嵌套对象会合并，数组会整体替换。渲染配置中的 `theme` 优先于构造函数中的主题，便于单张图表使用不同外观。Summary 使用构造函数主题渲染 T8 文本，没有单次渲染的 style 对象。

关系图中，固定的 `style.node.fill` 或 `charts['network-graph'].style.node.fill` 会覆盖分类颜色。需要沿用调色板时，不要设置固定的节点填充色。
