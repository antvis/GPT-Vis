GPT-Vis 提供 **28 种分析标注**和 6 种基础标注，通过图表配置的 `annotations` 数组使用。分析标注计算选择结果或位置，再复用基础标注完成绘制。

[查看全部 28 种交互示例](/examples/annotations)，切换支持的图表类型，复制完整配置。

本页对应当前源码。使用 npm 或 CDN 构建前，请确认所选版本包含需要的标注；安装 Skill 不会给旧版 SDK 增加能力。

<h2 id="start-with-one-annotation">从一个标注开始</h2>

```json
{
  "type": "line",
  "data": [
    { "time": 1, "value": 20 },
    { "time": 2, "value": 50 },
    { "time": 3, "value": 30 },
    { "time": 4, "value": 70 }
  ],
  "annotations": [{ "type": "mean" }]
}
```

均值使用图表已有的 `value` 映射，自动计算并绘制虚线参考线和默认说明，无需预先计算结果。

<h2 id="configuration-rules">配置职责</h2>

- `type` 选择标注。公共 TypeScript 入口为 `Annotation<T>`，`T` 是原始数据行。
- `data` 描述原始数据目标、位置或表格字段。使用图表原始字段，不传渲染库内部配置。对象选择器按全部给定字段等值匹配；对象数组取并集，重复目标不重复计数。
- `n`、`threshold`、`range`、`p`、`weight`、`minProminence`、`minDistance` 等算法参数放在 `data` 外层。
- [`label`](/docs/reference/annotation-options#label) 遵循共用标签规则：省略时使用分析标注默认说明，传完整字符串覆盖，传 `""` 隐藏。
- [`style`](/docs/reference/annotation-options#annotation-style) 通过 `AnnotationStyle<Type>` 限定该标注支持的字段。默认跟随图表主题；交叉箭头保留绿色／红色的方向语义。不向 point 或 highlight 传入内部的 `shape`、`halo`。
- 同一图表推荐只使用一种主强调，如 `topN`、`group` 或 `thresholdHighlight`，可搭配参考线或区间。不同强调类型同时修改同一图形时，样式优先级不属于受支持的约定。

逻辑 X/Y 指转置前的数据映射：折线／面积为 `time/value`，柱／条为 `category/value`，散点为 `x/y`。条形图的逻辑 Y 是屏幕上的水平数值轴。饼图使用 `category/value`。

```typescript
import type { Annotation } from '@antv/gpt-vis';

type Row = { time: number; value: number };
const annotations: Annotation<Row>[] = [
  { type: 'topN', n: 2 },
  { type: 'thresholdY', threshold: 40, label: 'Reference' },
];
```

<h2 id="all-28-analysis-annotations">28 种分析标注</h2>

下表配置是 `annotations` 中的一项，不是完整图表。示例使用折线的 `time/value` 或散点的 `x/y` 字段；按实际图表调整选择器。表格需使用下文的字段映射。

| -------------------- | ---------------------------------------------- | ---------------------------------------------- |
| `maxX`               | 选择 X 数值或 ISO 日期最大的所有观测。         | `{"type":"maxX"}`                              |
| `minX`               | 选择 X 数值或 ISO 日期最小的所有观测。         | `{"type":"minX"}`                              |
| `maxY`               | 选择数值最大的所有观测。                       | `{"type":"maxY"}`                              |
| `minY`               | 选择数值最小的所有观测。                       | `{"type":"minY"}`                              |
| `first`              | 按输入顺序选择候选数据的首项。                 | `{"type":"first"}`                             |
| `last`               | 按输入顺序选择候选数据的末项。                 | `{"type":"last"}`                              |
| `peak`               | 逐系列自动检测局部峰值。                       | `{"type":"peak"}`                              |
| `valley`             | 逐系列自动检测局部谷值。                       | `{"type":"valley"}`                            |
| `topN`               | 按数值从大到小选择前 N 项。                    | `{"type":"topN","n":3}`                        |
| `bottomN`            | 按数值从小到大选择 N 项。                      | `{"type":"bottomN","n":3}`                     |
| `thresholdHighlight` | 强调高于阈值的部分；direction 可切换为 below。 | `{"type":"thresholdHighlight","threshold":40}` |

| `outlier`            | 使用 IQR 围栏自动检测数值异常。                | `{"type":"outlier"}`                           |
| `group`              | 选择完整命名系列。                             | `{"type":"group","data":{"group":"Actual"}}`   |
| `contribution`       | 所选值求和后除以全部输入值的总和。             | `{"type":"contribution","data":{"time":3}}`    |

| `thresholdY`         | 在逻辑 Y 轴指定值绘制贯穿参考线。              | `{"type":"thresholdY","threshold":40}`         |
| `target`             | 绘制固定目标线或有序的变化基准路径。           | `{"type":"target","target":60}`                |
| `event`              | 在一个或多个事件位置绘制轴向线。               | `{"type":"event","data":{"time":3}}`           |
| `rangeX`             | 绘制逻辑 X 轴区间。                            | `{"type":"rangeX","range":[2,4]}`              |
| `rangeY`             | 绘制逻辑 Y 轴区间。                            | `{"type":"rangeY","range":[20,60]}`            |
| `quadrant`           | 绘制四个命名判定区域和两条分界线。             | `{"type":"quadrant","data":{"x":3,"y":40}}`    |
| `centroid`           | 自动计算散点中心，可使用权重。                 | `{"type":"centroid"}`                          |
| `crossing`           | 自动计算向上／向下阈值穿越或两个系列的交点。   | `{"type":"crossing","threshold":40}`           |

<h2 id="selection-ranking-and-peaks">极值、排名与峰谷</h2>

- `maxX/minX` 要求 X 为数值或 ISO 日期，不能使用任意分类名称。`maxY/minY` 比较有限数值。并列极值全部选中。
- `first/last` 使用筛选后的输入顺序，不按坐标或选择器数组排序。多系列时取整体候选的首尾。
- `topN/bottomN` 的 `n` 必须为正整数，最多选择 N 项，同值保留输入顺序。多系列整体排名；需要单系列排名时先用 `data` 限定。默认逐项显示名次，饼图显示在扇区内部。
- `peak/valley` 只用于有序折线／面积序列。`minProminence` 默认 0，单位为原始数值；`minDistance` 默认 1，单位为观测位置，不是时间或像素。按系列原值分别检测，不检测堆叠后的累计边界。缺失或非有限值断开序列，端点不作为峰谷。平台取中间位置，偶数长度取靠前位置。先检测，再用 `data` 筛选结果。

Top N 可通过完整 `label` 字符串覆盖说明，或用 `label: ""` 隐藏全部名次。每项需要不同自定义文字时，分别配置显式 `highlight`。

```json
[
  { "type": "topN", "n": 2, "data": { "group": "Actual" }, "label": "Key result" },
  { "type": "peak", "minProminence": 10, "minDistance": 3 }
]
```

<h2 id="thresholds-and-intervals">阈值与区间</h2>

`thresholdX/thresholdY` 只绘制阈值参考线。`thresholdHighlight` 还修改原图形：折线越界线段变色；面积、柱、条只改变超出部分的填充；散点和表格选择符合条件的观测。`direction` 默认 `"above"`，可设 `"below"`；`inclusive` 默认 false。折线／面积的 `data` 必须选择完整系列。阈值须为有限数值。

`rangeX/rangeY` 只绘制区间，另一轴覆盖绘图区。边界须同类型；数值须有限且有序，字符串须对应分类或时间位置。`rangeInside/rangeOutside` 还按数值选择观测：区间内包含端点，区间外严格排除端点。统计图包含参考区间背景，表格只强调对应行／单元格。

```json
[
  { "type": "thresholdHighlight", "threshold": 40, "direction": "below", "inclusive": true },
  { "type": "rangeX", "range": [2, 4] }
]
```

<h2 id="outliers-series-and-contribution">异常值、系列与贡献</h2>

`outlier` 使用严格 IQR 围栏，选择 `[Q1 − factor × IQR, Q3 + factor × IQR]` 之外的值，四分位数采用 R-7 插值。`factor` 默认 1.5，须为正有限值。每个候选系列至少需要 4 个有限数值。散点只检测 Y 数值，不检测空间距离，也不识别季节性或上下文异常。外部算法已经判定的目标使用 `highlight`。

`group` 只接受 `{ "group": "Actual" }` 或多个完整系列名称。图表必须已有系列映射，柱／条还需开启 `group: true` 或 `stack: true`。默认逐个显示所选系列的名称和色块，无引线；自定义 `label` 时改用一条共用说明，`label: ""` 隐藏说明。这不执行聚类；饼图／表格的多项选择、网络图节点／边应使用 `highlight`。

`contribution` 对所选观测求和，重叠选择去重后，除以**全部输入观测**的总和，不以筛选子集为分母。数值须非负且可加总；总和为零时不绘制。无需传入 `total` 或 `share`。饼图单项贡献尽量复用可见的原生百分比，避免重复标签。

贡献说明使用汇总括线和一条合计标签：柱、折线、面积、散点放在选中项上方，条图和表格放在右侧。从第一个可见选中项括到最后一个，不再逐项连接引线。统计图中未选中观测默认降至原透明度的 16%，可用 `style.dimOpacity` 覆盖。多个强调标注保留所选目标并集的原透明度，说明标签共同参与避让。

饼图贡献使用外侧弧形括线：连续的选中扇区合并，不连续的选中扇区分段括起，共用一条合计说明，不把未选中的扇区括入范围。highlight 默认保留图形原色和原有边框，未选中项降至原透明度的 16%；显式配置的 `style.stroke`、`style.lineWidth` 和 `style.dimOpacity` 仍然生效。数据文字描边独立保留。

<h2 id="statistics-targets-and-events">统计参考、目标与事件</h2>

`mean/median/quantile` 计算 `axis` 上的有限数值，默认 `"y"`；`data` 可限定候选数据。空集不绘制。quantile 必须提供 [0, 1] 内的 `p`，使用 R-7 插值。轴向参考线默认虚线并跟随主题文字色，显式 `style.stroke` 优先。

`target` 可以提供有限的固定 `target` 值（`axis` 默认 `"y"`），或至少两个完整位置组成的 `data` 变化基准路径，两者不能同时提供。

`event` 默认 `axis: "x"`，接受一个／多个轴位置，也可使用能唯一定位数据行的选择器。它绘制事件线和说明，不检测变化点。

```json
[
  { "type": "quantile", "p": 0.95, "data": { "group": "Actual" } },
  {
    "type": "target",
    "data": [
      { "time": 1, "value": 30 },
      { "time": 4, "value": 60 }
    ]
  },
  { "type": "event", "data": [{ "time": 2 }, { "time": 4 }], "label": "Campaign" }
]
```

<h2 id="scatter-regions-and-centers">散点判定区域与中心</h2>

`quadrant` 的 `data` 必须包含两个数值轴的分界值。`labels` 分别覆盖 `topRight`、`topLeft`、`bottomLeft`、`bottomRight`，单个名称设为 `""` 隐藏该名称。`label` 控制两条分界线说明，`label: ""` 隐藏全部文字。

`centroid` 对有效数值坐标对计算普通中心。`weight` 指定原始数据中的权重字段，权重须有限、非负且总和大于零。中心是计算位置，默认用十字标记、无光晕；`pulse: true` 可开启。

```json
[
  {
    "type": "quadrant",
    "data": { "x": 3, "y": 40 },
    "labels": {
      "topRight": "High investment / high return",
      "topLeft": "Low investment / high return",
      "bottomLeft": "Low investment / low return",
      "bottomRight": "High investment / low return"
    }
  },
  { "type": "centroid", "weight": "weight" }
]
```

<h2 id="crossings">交叉与阈值突破</h2>

阈值穿越提供有限的 `threshold`，可用 `data` 选择一个系列。双系列求交省略 `threshold`，在 `data.series` 提供恰好两个不重叠的系列选择器。方向以第一个系列相对于第二个系列判断：`"up"`、`"down"` 或默认的 `"both"`。

只支持未堆叠的折线／面积。原生曲线形状支持 `line`／`linear`、`smooth`、`hv`、`vh`、`hvh`，其他形状会被拒绝。每个系列的 X 必须唯一，数值 X 须单调。数值系列只在共同定义域内求交，不外推；分类 X 使用穿越后的实际观测，不伪造中间分类。缺失值断开路径；接触后返回原侧不记为穿越，等值平台换侧时取首个等值位置。

三角形保留绿色／红色的固定方向语义，并针对深色背景调整。面积图不会在原有面积上叠加另一层方向色填充。

```json
[
  { "type": "crossing", "threshold": 40, "direction": "down" },
  { "type": "crossing", "data": { "series": [{ "group": "Actual" }, { "group": "Budget" }] } }
]
```

<h2 id="drawing-primitives">基础标注</h2>

以下 6 种能力绘制调用方给定的位置或强调已有内容，不推断分析结论。

| type        | 最简配置                                                                | 限制                                                       |
| ----------- | ----------------------------------------------------------------------- | ---------------------------------------------------------- |
| `path`      | `{"type":"path","data":{"value":40}}`                                   | 单轴值贯穿绘图区；有序数组连接至少两个锚点。               |
| `range`     | `{"type":"range","data":{"value":[20,60]}}`                             | 只接受轴字段，未限定的轴覆盖绘图区。                       |
| `point`     | `{"type":"point","data":{"time":2,"value":50}}`                         | 一个或多个独立标记，pulse 默认动画。                       |
| `connector` | `{"type":"connector","data":[{"time":1},{"time":4}],"label":"Compare"}` | 恰好两个锚点，shape 支持 line、curve、dimension、bracket。 |
| `text`      | `{"type":"text","data":{"time":2,"value":50},"label":"Note"}`           | label 必填。                                               |
| `highlight` | `{"type":"highlight","data":{"time":2}}`                                | 选择已有内容，不推断新的数据点。                           |

6 种基础标注均支持折线、面积、柱、条、散点。网络图支持 path、point、connector、text、highlight，path 必须使用锚点数组。饼图、表格、摘要在基础标注中仅支持 highlight。其他关系／层级图尚未接入。

定位时，完整轴字段表示独立坐标，其他选择器须唯一定位数据行。网络图锚点使用 `name` 等原始节点字段；边强调可使用原始 `source` 和 `target`。`connector.orientation` 为 `"horizontal"` 或 `"vertical"`，用于 dimension／bracket，控制比较跨度的方向。

<h2 id="table-and-summary-targets">表格与摘要的数据目标</h2>

表格 highlight 用 `data.row` 选择行，`data.column` 可限定强调列；只给 column 时强调整列。计算标注须提供 `data.field`，可选 `row` 限定候选行、`column` 指定强调列。这是表格映射，不是统计图的字段覆盖配置。contribution 必须给 row，分母仍包含全部行。

```json
{
  "type": "table",
  "data": [
    { "product": "Basic", "revenue": 20 },
    { "product": "Pro", "revenue": 60 },
    { "product": "Team", "revenue": 40 }
  ],
  "annotations": [{ "type": "topN", "n": 1, "data": { "field": "revenue", "column": "revenue" } }]
}
```

摘要接受 T8 文本；需要外部强调时可传入 `{ type: "summary", text, annotations }`。`data.text` 须为非空且能唯一匹配可见文字，可跨 T8 行内片段。主题通过构造参数传入。

```json
{
  "type": "summary",
  "text": "Revenue reached [240](metric_value).",
  "annotations": [{ "type": "highlight", "data": { "text": "240" }, "label": "Revenue" }]
}
```

<h2 id="annotation-styles">标注样式</h2>

共享的 `label` 规则、`AnnotationStyle<Type>` 字段定义、各类型支持范围和 TypeScript 复用示例统一见[标注配置参考](/docs/reference/annotation-options)。报告整体外观使用[主题](/docs/themes)。
