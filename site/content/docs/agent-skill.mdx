The chart-visualization Skill teaches a compatible agent how to select charts, generate JSON or Syntax, write integration code, and create themes from brand references. It uses your agent’s existing model.

## Install with your agent

Copy the installation prompt below and paste it into an assistant that can install Skills from a link. It asks the assistant to download the complete Skill, check its reference files, and report where it was installed. Use the same prompt across clients; their supported installation locations may differ.

### Upload a Skill

Claude also supports [adding plugin marketplaces from Git repositories](https://support.claude.com/en/articles/13837440-use-plugins-in-claude). That requires a plugin marketplace structure. This repository currently distributes a standalone Skill, so ZIP upload is the documented import route we provide for Claude Chat and Cowork.

[Download the Skill ZIP](/downloads/chart-visualization.zip). It contains one `chart-visualization/` folder with SKILL.md and all bundled references. Upload the complete package using your client's custom Skill import flow, then check that the Skill is enabled. Do not upload the whole GPT-Vis repository or just SKILL.md.

### Terminal installation

Run this command from your project folder. The third-party skills installer lets you choose the target agent:

```bash
npx skills add https://github.com/antvis/GPT-Vis/tree/ai --skill chart-visualization
```

### Manual installation

Copy the complete [chart-visualization directory](https://github.com/antvis/GPT-Vis/tree/ai/skills/chart-visualization), including its references, into your assistant's supported Skills location. Follow its discovery and restart instructions. For team use, choose a project-scoped location when your tool supports one.

## Create your first chart

After installation, start a new agent session if your tool requires it. Try this task with a small, fixed dataset:

```text
Use the GPT-Vis chart-visualization skill to create a monthly revenue report from these values (USD): Jan 12000, Feb 18000, Mar 15000, Apr 24000.

Include a line chart, a table with the same four values, and a short summary of the total revenue and April's change from March. Calculate the figures from the supplied data.

Use a shared theme configuration for the chart and table. Create report.html that I can open directly in a browser, with the theme embedded and any published library dependencies loaded. Also save the same theme configuration as theme.json so I can reuse it. No build step should be needed.
```

The deliverables should contain the same four values, with matching visual styling. Open the generated HTML in your browser, or import its theme JSON into [Theme Studio](/themes) to compare it across chart types.

## Create a theme from a reference

Give your agent a website, slide, brand guide, or visual reference and ask it to follow the bundled Theme Creator reference. Request a theme JSON object that works across statistical charts, relationship graphs, tables, and text summaries.

Keep category colors in the palette. A fixed `style.node.fill`, or a fixed node fill in a relationship chart override, can replace palette colors and make every node look the same. Use one only when that uniform appearance is intentional.

## Check the installation

- Verify the complete chart-visualization directory and its references are installed in the directory supported by your tool.
- Ask the agent to read the installed SKILL.md. Restart the session if skills are discovered only at startup.
- If local installation is unavailable, use the source as a reference in a tool that can read it, or follow its supported manual installation flow.

The terminal command installs a Skill through the third-party skills installer. GPT-Vis does not currently ship a separate chart CLI. [MCP and other integrations](/docs/integrations/ecosystem) are separate ways to connect rendering tools.
