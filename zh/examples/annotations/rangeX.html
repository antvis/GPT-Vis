区间与区域 / 标注指南

rangeX

绘制逻辑 X 轴区间，另一轴覆盖绘图区。

实时示例2配置图表支持5配置指南与支持矩阵

适用场景

  • 展示轴上的重要区间。
  • 在观测值后方保留参考区域。

02 / 配置图表

按需调整图表。

将以下配置添加到图表 JSON 的 annotations 数组中。

配置

属性类型必填说明
type'rangeX'必填准确的标注类型；请保留此处的拼写与大小写。
range[number, number] | [string, string]必填按顺序排列的数值边界，或对应轴的时间、类别边界。
labelstring可选覆盖自动生成的标签；使用空字符串可隐藏标签。
styleAnnotationStyle<'rangeX'>可选引用共用样式定义，使用该标注类型支持的字段。

03 / 图表支持

选择支持的图表。

每种支持的图表各有一个示例。默认图表已在上方展示，其余图表使用相同的标注配置。

  • 折线图
  • 面积图
  • 柱状图
  • 条形图
  • 散点图

计算规则与限制

  • 另一条轴覆盖整个绘图区。数值边界必须有限且按顺序排列。
