将主题用在其他地方

内置主题可按名称使用。自定义后，导出 JSON 并传入完整的主题对象。

import { GPTVis } from '@antv/gpt-vis';

const chart = new GPTVis({
  container: '#chart',
  theme: 'default',
});

chart.render({
  type: 'line',
  data: [
    { time: 'Q1', value: 32 },
    { time: 'Q2', value: 48 },
    { time: 'Q3', value: 61 },
  ],
});

请根据我提供的网站、幻灯片、品牌规范或视觉参考，为 GPT-Vis 创建自定义主题。

先阅读并遵循 chart-visualization Skill 随附的独立主题创建指南：
https://raw.githubusercontent.com/antvis/GPT-Vis/ai/skills/chart-visualization/references/theme-creator.md

若无法访问，使用：
https://github.com/antvis/GPT-Vis/blob/ai/skills/chart-visualization/references/theme-creator.md

仅询问会实质影响设计的缺失信息。遵循指南中的配置字段、视觉样式边界、可访问性要求和校验步骤，让统计图、关系图、表格和文字摘要使用一致的风格。

只返回一个完整的主题 JSON 对象，包含 id 和 label，可直接粘贴到 GPT-Vis 主题工作台。使用 tokens 定义公共样式，使用 style/charts 调整支持的视觉细节。不要包含图表数据、解释文字、Markdown 围栏或其他图表库的字段。
