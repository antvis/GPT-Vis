19:Te69,# 图表类型

根据数据选择图表，了解各类图表的配置。

根据要表达的数据关系选择图表。GPT-Vis 支持 **26 种可视化类型**，每个示例页都提供数据字段、配置项及 JSON 或 Syntax 示例。

## 趋势与比较

| 分析目标     | 图表类型                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| 随时间变化   | [折线图](/zh/examples/line-chart)、[面积图](/zh/examples/area-chart)                                      |
| 比较类别     | [条形图](/zh/examples/bar-chart)、[柱状图](/zh/examples/column-chart)、[雷达图](/zh/examples/radar-chart) |
| 组合两个指标 | [双轴图](/zh/examples/dual-axes)                                                                          |
| 展示逐步增减 | [瀑布图](/zh/examples/waterfall-chart)                                                                    |

## 构成与分布

| 分析目标     | 图表类型                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| 整体与部分   | [饼图](/zh/examples/pie-chart)、[矩形树图](/zh/examples/treemap)                                        |
| 阶段与流向   | [漏斗图](/zh/examples/funnel-chart)、[桑基图](/zh/examples/sankey-diagram)                              |
| 数据分布     | [直方图](/zh/examples/histogram)、[箱线图](/zh/examples/boxplot)、[小提琴图](/zh/examples/violin-chart) |
| 数值间的关系 | [散点图](/zh/examples/scatter-chart)、[韦恩图](/zh/examples/venn-diagram)                               |
| 进度与词频   | [水波图](/zh/examples/liquid-chart)、[词云](/zh/examples/wordcloud)                                     |

## 关系与层级

| 分析目标       | 图表类型                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------- |
| 实体之间的关联 | [关系网络图](/zh/examples/network-graph)                                                                              |
| 流程步骤       | [流程图](/zh/examples/flow-diagram)                                                                                   |
| 层级结构       | [组织结构图](/zh/examples/organization-chart)、[缩进树](/zh/examples/indented-tree)、[思维导图](/zh/examples/mindmap) |
| 整理可能的原因 | [鱼骨图](/zh/examples/fishbone-diagram)                                                                               |

## 表格与文字

使用[表格](/zh/examples/table)保留精确数值，用[摘要](/zh/examples/summary)呈现带有样式的分析文字。摘要内容由应用提供或由 Agent 生成，渲染器本身不执行分析。

## 跨图表统一主题

在[首页主题预览](/zh/#themes)中比较不同风格，或打开[主题工作台](/zh/themes)预览所有图表类型。工作台支持预览、编辑和导出主题配置。

进一步阅读[主题](/zh/docs/themes)和[图表样式](/zh/docs/styles)。

## 分析标注

通过 [28 种分析标注和 6 种基础标注](/zh/docs/annotations)展示结论。各图表支持的能力不同，以支持矩阵和[交互示例](/zh/examples/annotations)为准，不默认所有图表支持全部标注。
