18:T73a,# 图表样式

覆盖单张图表的样式，了解局部样式与公共主题的关系。

使用 `theme` 统一整份报告的外观。如果某张图表需要不同的配色或图形样式，在渲染配置中设置 `style`。

## 单独调整一张图表

下面的图表直接在渲染配置中设置配色和线宽。

```typescript
chart.render({
  type: 'line',
  title: 'Monthly revenue',
  data: [
    { time: 'Jan', value: 120 },
    { time: 'Feb', value: 180 },
    { time: 'Mar', value: 150 },
  ],
  style: {
    palette: ['#176b68'],
    mark: { line: { lineWidth: 4 } },
  },
});
```

## 分类配色

`style.palette` 为类别或系列分配颜色。可复用的主题也可以通过 `tokens.category10` 或 `tokens.category20` 设置配色。

```text
vis column
data
  - category Design
    value 30
  - category Engineering
    value 45
style
  palette
    - #176b68
    - #d38452
```

## 样式命名空间

| 图表类别 | 常用样式块 |
| ------------------- | -------------------------------------------------------------------- |
| 统计图 | `title`、`axis`、`legend`、`label`，以及各图表支持的 `mark` 样式块 |
| 关系图 | `node`、`edge` 及受支持的标签样式 |
| 表格 | `table.header`、`table.cell`、`table.border` |
| 摘要 | 构造函数主题配置中的 `summary` |

各图表支持的字段不同，请参考[图表示例](/zh/examples)和[主题配置参考](/zh/docs/reference/theme-spec)，不要直接复制 G2 或 G6 的配置。主题用于调整已有图形的外观，不会添加图形或改变图表结构。

## 保留节点分类配色
