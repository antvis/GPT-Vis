15:Tdbb,# Chart types

Find a chart for your data and explore its options.

Choose a chart for the relationship you want to show. GPT-Vis supports **26 visualization types**. Each example page includes data fields, supported options, and JSON or Syntax configurations.

## Trends and comparisons

| Goal                    | Chart types                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| Change over time        | [Line](/examples/line-chart), [Area](/examples/area-chart)                                   |
| Compare categories      | [Bar](/examples/bar-chart), [Column](/examples/column-chart), [Radar](/examples/radar-chart) |
| Combine two measures    | [Dual axes](/examples/dual-axes)                                                             |
| Show sequential changes | [Waterfall](/examples/waterfall-chart)                                                       |

## Composition and distribution

| Goal                         | Chart types                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| Parts of a whole             | [Pie](/examples/pie-chart), [Treemap](/examples/treemap)                                         |
| Stages and flows             | [Funnel](/examples/funnel-chart), [Sankey](/examples/sankey-diagram)                             |
| Distribution                 | [Histogram](/examples/histogram), [Boxplot](/examples/boxplot), [Violin](/examples/violin-chart) |
| Relationships between values | [Scatter](/examples/scatter-chart), [Venn](/examples/venn-diagram)                               |
| Progress or text frequency   | [Liquid](/examples/liquid-chart), [Word cloud](/examples/wordcloud)                              |

## Relationships and hierarchies

| Goal                     | Chart types                                                                                                                |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Connected entities       | [Network graph](/examples/network-graph)                                                                                   |
| Process steps            | [Flow diagram](/examples/flow-diagram)                                                                                     |
| Hierarchical structure   | [Organization chart](/examples/organization-chart), [Indented tree](/examples/indented-tree), [Mindmap](/examples/mindmap) |
| Organize possible causes | [Fishbone diagram](/examples/fishbone-diagram)                                                                             |

## Tables and text

Use [Table](/examples/table) for exact values and [Summary](/examples/summary) for styled narrative text. Supply the summary text yourself or generate it with your agent; the renderer does not perform the analysis.

## One theme across chart families

Compare a few styles in the [homepage theme showcase](/#themes), or open [Theme Studio](/themes) to preview all chart types. [Theme Studio](/themes) lets you preview, edit, and export a theme configuration for the chart types you use.

See [themes](/docs/themes) and [chart styling](/docs/styles).
